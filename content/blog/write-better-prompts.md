A clear prompt helps the image model understand what should appear in the result. You do not need a long prompt; a few concrete details usually work better than a list of vague adjectives.

## Start with the subject

Say what should be the focus of the image. If there is an action, describe it directly.

## Add the setting

Describe where the scene takes place and the time of day. These details help establish context.

## Define the visual direction

Add useful notes about lighting, color, mood, and composition. Use plain language that clearly distinguishes one choice from another.

## Review before you generate

Read the prompt once and remove repeated ideas. Check that the selected template and image ratio support the result you want.
