# PicVilo AI（暂定）首页内容结构交接包

以 https://rapvideo.ai/zh 的页面信息架构为参考，创作一个面向 AI 图片 + AI 视频的原创营销/产品长首页。保留 Hero 和原三栏 AI 创作工作台在顶部，其下依次为产品解释、案例、工具、教程、玩法、上传建议、工具目录、积分价格、FAQ、末屏 CTA 与 Footer。

## 文件

- `首页内容原型.html` —— 独立离线 HTML 可交互演示，**无后端/不生成图片**。桌面和手机均可预览。
- `首页桌面预览.png` / `首页手机预览.png` —— 完整长度截图（生成时验证布局）。
- `01_首页完整结构与中文文案.md` —— 中国语境文案及每个区块完整内容。
- `02_SEO_GEO_实施与路由.md` —— 首页元信息、关键词承接、GEO、结构化数据与内链策略。
- `03_Codex_首页开发交付指令.md` —— Codex 可直接读取的实施计划、数据结构和验收。
- `04_英文首页核心文案.md` —— 出海站英文版核心文案。

## 重要范围边界

1. 不开发模板管理后台。
2. 用户图片上传最多一张，模板封面 3:4；完整模板提示词只存服务端。
3. 视频生成是否可用取决于真实后端，原型将视频标注为规划模块。
4. 积分价格示意不能用于真实收费。实际计费由服务端报价。
5. 禁止 NSFW 成人露骨性内容；用户作品默认私密。
6. 原型中所用图片来自此前用户提供的设计参考和示意素材；**正式商业站须核验授权或替换成自有作品**。
7. PicVilo AI 是临时品牌，不表示域名、商标可注册。
